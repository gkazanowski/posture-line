From installing PyCharm
to your first commit

A step-by-step guide to installing the tools, cloning the repository, running the application, and contributing changes.

1. Install PyCharm

  1. Open the PyCharm download page.
  2. Download and run the Windows installer.
  3. You can keep the default settings. Enable Open Folder as Project to open projects from File Explorer.
  4. Complete the installation.

PyCharm is available as a unified product with free core features. This project does not require a paid subscription. You can continue using the free features after the Pro trial ends. See the installation documentation.

2. Install Python 3.12

The project requires Python 3.10–3.12. Use 64-bit Python 3.12 for this guide.

  1. Open the Python 3.12.10 release page.
  2. Under Files, download Windows installer (64-bit).
  3. Run the installer and select Add python.exe to PATH.
  4. Select Install Now.
  5. Open PowerShell and check the installation:
py -3.12 --version

Expected output: Python 3.12.x.

The current project configuration does not support Python 3.13 or later. Select Python 3.12 when configuring PyCharm as well.

3. Install Git

  1. Download the installer from the official Git for Windows page.
  2. Install it with the default settings.
  3. Open a new PowerShell window and check:
git --version

If PyCharm was open while you installed Git, restart PyCharm.

4. Clone the repository in PyCharm

  1. On the welcome screen, select Clone Repository or Get from VCS. If a project is already open, look for Git → Clone.
  2. Paste the following address into the URL field:
https://github.com/gkazanowski/posture-line.git

In Directory, select a local folder, for example the path below. Replace YOUR_USERNAME with your Windows username.

C:\Users\YOUR_USERNAME\PycharmProjects\posture-line

Click Clone, open the project, and select Trust Project if prompted.

The repository is public, so cloning does not require a GitHub login. Button names may differ between PyCharm versions. See the cloning instructions.

5. Create the environment and install dependencies

Open the Terminal tab in PyCharm and use PowerShell. Make sure you are in the posture-line directory: dir should list pyproject.toml.

Create a dedicated Python environment for the project:

py -3.12 -m venv .venv

Then install the application and its dependencies:

.\.venv\Scripts\python.exe -m pip install -c requirements-lock.txt -e .
The final dot is part of the command. If PyCharm has already created a Python 3.12 environment in .venv, skip environment creation and install the dependencies. The .venv directory is not downloaded from GitHub; each contributor creates it locally.

6. Add the interpreter to PyCharm

  1. Press Ctrl+Alt+S and search for Python Interpreter. In newer versions, it is under Python → Interpreter.
  2. Select Add Interpreter → Add Local Interpreter.
  3. Select an existing environment: Existing environment or the Python type, depending on your version.
  4. Click the browse button … or folder icon and locate this file in your project directory:
YOUR_PROJECT_FOLDER\.venv\Scripts\python.exe

Confirm with OK / Apply. Replace YOUR_PROJECT_FOLDER with the full path to your cloned posture-line directory.

If the interpreter is missing from the list, add it by browsing for the executable. An interpreter from an older project, such as PyCharmMiscProject, may not have this application installed.

See the interpreter configuration documentation.

7. Run the application

Select the Posture Line configuration in the PyCharm toolbar and click the green Run button.

If the configuration is missing, open Run → Edit Configurations… → + → Python and set:

FieldValue
NamePosture Line
Run / Module nameposture_line
Python interpreterThe interpreter from the project's .venv
Working directoryThe full path to your local posture-line directory

Select module execution and enter exactly posture_line, without extra spaces or slashes. Do not run main.py; it is a PyCharm sample file.

Alternatively, run the application from the project terminal:

.\.venv\Scripts\python.exe -m posture_line

Click Start camera in the application. The first run downloads the model and requires internet access. If the camera is busy, close other applications using it.

8. Run the tests

Run this command in the project terminal:

.\.venv\Scripts\python.exe -m unittest discover -s tests -v

The baseline version described in this guide includes 9 tests. A successful run ends with OK. Later versions may include more tests.

9. Start contributing

Configure the commit author for this repository. Replace the example values with your own details:

git config user.name "Your Name"
git config user.email "your-email@example.com"

Before starting new work, with a clean working tree, download updates and create your own branch:

git switch main
git pull --ff-only
git switch -c feature/my-first-change

Make your changes, run the tests from step 8, then create a commit and push your branch:

git status
git add src tests
git commit -m "Improve posture visualization"
git push -u origin feature/my-first-change

git add src tests stages changes in those two directories. Stage other changed files, such as README.md, separately. Choose a branch name and commit message that describe your change.

All project content must be in English, including code, file and branch names, commit messages, comments, UI text, and documentation. This includes onboarding guides and downloadable materials.

To push directly to gkazanowski/posture-line, you need collaborator access and GitHub authentication. After pushing your branch, open a Pull Request targeting main.

Without write access, create a fork on GitHub, clone your fork's address instead of the address in step 4, and push branches to your fork. Then open a Pull Request from your fork to gkazanowski/posture-line.
