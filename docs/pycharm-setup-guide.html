1. Zainstaluj PyCharma

  1. Otwórz stronę pobierania PyCharma.
  2. Pobierz instalator dla Windows i uruchom go.
  3. Możesz pozostawić ustawienia domyślne. Opcja Open Folder as Project ułatwia otwieranie projektów z Eksploratora.
  4. Dokończ instalację.

PyCharm jest obecnie jednym produktem z bezpłatnymi podstawowymi funkcjami. Do tego projektu nie potrzebujesz płatnej subskrypcji. Po okresie próbnym Pro możesz nadal korzystać z funkcji bezpłatnych. Dokumentacja instalacji.

2. Zainstaluj Pythona 3.12

Projekt wymaga Pythona 3.10–3.12. Dla tej instrukcji wybierz Python 3.12, 64-bit.

  1. Otwórz stronę Pythona 3.12.10.
  2. W sekcji Files pobierz Windows installer (64-bit).
  3. Uruchom instalator i zaznacz Add python.exe to PATH.
  4. Wybierz Install Now.
  5. Otwórz PowerShell i sprawdź instalację:
py -3.12 --version

Oczekiwany wynik: Python 3.12.x.

Aktualna konfiguracja projektu nie obsługuje Pythona 3.13 ani nowszego. Wybierz wersję 3.12 również podczas konfiguracji PyCharma.

3. Zainstaluj Git

  1. Pobierz instalator z oficjalnej strony Git dla Windows.
  2. Zainstaluj go z ustawieniami domyślnymi.
  3. Otwórz nowe okno PowerShell i sprawdź:
git --version

Jeżeli PyCharm był otwarty podczas instalacji Gita, uruchom go ponownie.

4. Pobierz repozytorium w PyCharmie

  1. Na ekranie powitalnym wybierz Clone Repository lub Get from VCS. Jeżeli masz otwarty projekt, poszukaj Git → Clone.
  2. W polu URL wklej poniższy adres.
https://github.com/gkazanowski/posture-line.git

W polu Directory wybierz folder na swoim komputerze, np. poniższy. Zastąp TWOJ_LOGIN swoją nazwą użytkownika Windows.

C:\Users\TWOJ_LOGIN\PycharmProjects\posture-line

Kliknij Clone, otwórz projekt i wybierz Trust Project, jeśli pojawi się pytanie o zaufanie do projektu.

Repozytorium jest publiczne, więc samo pobranie nie wymaga logowania do GitHuba. Nazwy przycisków mogą różnić się między wersjami PyCharma. Instrukcja klonowania.

5. Utwórz środowisko i zainstaluj biblioteki

W PyCharmie otwórz zakładkę Terminal i użyj PowerShella. Upewnij się, że jesteś w folderze posture-line: polecenie dir powinno pokazać plik pyproject.toml.

Utwórz osobne środowisko Pythona dla projektu:

py -3.12 -m venv .venv

Następnie zainstaluj aplikację i jej zależności:

.\.venv\Scripts\python.exe -m pip install -c requirements-lock.txt -e .
Końcowa kropka jest częścią polecenia. Jeśli PyCharm wcześniej utworzył już .venv z Pythonem 3.12, pomiń tworzenie środowiska i wykonaj tylko instalację bibliotek. Folder .venv nie jest pobierany z GitHuba — każdy tworzy go lokalnie.

6. Dodaj interpreter do PyCharma

  1. Naciśnij Ctrl+Alt+S i wyszukaj Python Interpreter. W nowszych wersjach znajdziesz go pod Python → Interpreter.
  2. Wybierz Add Interpreter → Add Local Interpreter.
  3. Wybierz istniejące środowisko: Existing environment lub typ Python, zależnie od wersji.
  4. Kliknij ikonę przeglądania … lub folderu i wskaż plik poniżej, we własnym katalogu projektu.
FOLDER_TWOJEGO_PROJEKTU\.venv\Scripts\python.exe

Zatwierdź przez OK / Apply. W tej ścieżce FOLDER_TWOJEGO_PROJEKTU oznacza pełną ścieżkę do sklonowanego katalogu posture-line.

Jeśli właściwego interpretera nie ma na liście, dodaj go przez przeglądanie plików. Interpreter ze starszego projektu, np. PyCharmMiscProject, może nie mieć zainstalowanej naszej aplikacji.

Dokumentacja konfiguracji interpretera.

7. Uruchom aplikację

W górnym pasku PyCharma wybierz konfigurację Posture Line i kliknij zielony przycisk Run.

Jeśli konfiguracji nie ma, otwórz Run → Edit Configurations… → + → Python i ustaw:

PoleWartość
NamePosture Line
Run / Module nameposture_line
Python interpreterInterpreter z projektowego .venv
Working directoryPełna ścieżka do folderu posture-line na Twoim komputerze

Wybierz uruchamianie modułu, nie pliku. Wpisz dokładnie posture_line, bez dodatkowych spacji i ukośników. Nie uruchamiaj main.py — to przykładowy plik PyCharma.

Alternatywnie uruchom aplikację z terminala projektu:

.\.venv\Scripts\python.exe -m posture_line

W oknie aplikacji kliknij Start camera. Przy pierwszym uruchomieniu zostanie pobrany model, więc potrzebny jest internet. Jeśli kamera jest zajęta, zamknij inne aplikacje korzystające z niej.

8. Sprawdź testy

W terminalu projektu uruchom:

.\.venv\Scripts\python.exe -m unittest discover -s tests -v

Wersja bazowa opisana w tej instrukcji zawiera 9 testów. Poprawny wynik kończy się komunikatem OK. W kolejnych wersjach liczba testów może wzrosnąć.

9. Rozpocznij pracę nad zmianami

Ustaw autora commitów dla tego repozytorium. Zastąp przykładowe dane własnymi:

git config user.name "Your Name"
git config user.email "your-email@example.com"

Przed rozpoczęciem nowej pracy, przy czystym katalogu roboczym, pobierz aktualizacje i utwórz własną gałąź:

git switch main
git pull --ff-only
git switch -c feature/my-first-change

Wprowadź zmiany, uruchom testy z kroku 8, a następnie przygotuj commit i wyślij gałąź:

git status
git add src tests
git commit -m "Improve posture visualization"
git push -u origin feature/my-first-change

git add src tests dodaje zmiany z tych dwóch katalogów. Inne zmienione pliki, np. README.md, dodaj osobno. Dopasuj nazwę gałęzi i opis commita do swojej zmiany.

Kod, nazwy plików i gałęzi, komunikaty commitów, komentarze oraz dokumentację projektu prowadzimy po angielsku. Ta instrukcja po polsku służy wdrożeniu użytkownika i jest osobnym materiałem.

Do wysyłania zmian bezpośrednio do gkazanowski/posture-line potrzebujesz uprawnień współpracownika i logowania do GitHuba. Po wysłaniu gałęzi utwórz na GitHubie Pull Request do main.

Osoba bez dostępu do zapisu może utworzyć na GitHubie fork, sklonować adres własnego forka zamiast adresu z kroku 4 i wysyłać gałęzie do niego. Następnie zgłasza Pull Request z forka do gkazanowski/posture-line.
