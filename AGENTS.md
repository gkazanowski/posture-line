# Project conventions

- Communicate with the user in Polish unless requested otherwise.
- Keep all project content in English: file and directory names, identifiers, UI labels, messages, comments, docstrings, documentation, tests, and commit descriptions.
- The project is called **Posture Line**, the distribution is `posture-line`, and the Python package is `posture_line`.
- The user works in PyCharm. Keep run instructions and configuration compatible with PyCharm and use the project's `.venv` interpreter.
- Preserve the current prototype angle calculations until the user requests work on angles.
